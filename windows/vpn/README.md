# ПОМОГАТОР VPN v0.1.0

Локальное настольное приложение для Windows 10 x64 с интерфейсом WPF. Для подключения используется Xray-core 26.11.9. [Исходники Xray-core и лицензия MPL 2.0](https://github.com/XTLS/Xray-core/tree/v26.11.9) Учётная запись в приложении не требуется.

## Запуск

1. Распакуйте артефакт `PomogatorVpn-0.1.0-win-x64` из успешного запуска GitHub Actions или соберите комплект по инструкции ниже.
2. Запустите `PomogatorVpn.exe` из распакованной папки. `xray.exe` должен лежать рядом. Права администратора не требуются.
3. Импортируйте профиль, выберите его в списке и нажмите **Подключиться**. По умолчанию будет запущен HTTP-прокси на адресе `127.0.0.1` со свободным портом. Указанный в окне адрес можно задать в нужном приложении.
4. Если хотите использовать настройки прокси Windows, перед подключением выберите **Системный прокси** и подтвердите запрос. Нажмите **Отключиться** для завершения сеанса.

## Профили

Можно вставить ссылку `vless://` из буфера обмена, открыть файл или загрузить HTTPS-подписку. Поддерживаются списки до 100 ссылок в UTF‑8 или Base64, а также ограниченный клиентский JSON Xray с одним исходящим VLESS, одним сервером и одним пользователем. Из JSON импортируются параметры профиля. Правила маршрутизации и локальные слушатели строятся приложением. Некоторые поля ядра не поддерживаются.

Поддерживаются TLS, REALITY, SNI, fingerprint, Vision для TCP, TCP, WebSocket, gRPC, HTTPUpgrade и XHTTP. REALITY поддерживается ядром для TCP, XHTTP и gRPC. Профили без TLS или REALITY разрешены для локального теста. Профили, требующие отключить проверку TLS-сертификата, отклоняются.

URL подписки запрашивается у указанного поставщика напрямую по HTTPS без перенаправлений. URL подписки не сохраняется. Форматы, содержащие другие протоколы или неподдерживаемые поля, отклоняются с сообщением в окне.

## Системный прокси и восстановление

- Утилита меняет только параметры WinINet для LAN текущего пользователя. Подключения PPPoE могут иметь собственные параметры прокси, поэтому приложения на ПК с PPPoE могут потребовать ручного указания локального адреса. Раздача ICS, Wi-Fi, DNS и системные маршруты не изменяются.
- Режим отказывается заменять включённый ручной прокси или назначенный сценарий PAC. Работает одна копия ПОМОГАТОР VPN на пользователя. Если другая программа меняет применённые параметры, утилита освобождает системный прокси и оставляет ядро в локальном режиме. Windows не предоставляет общей блокировки между VPN-клиентами разных производителей.
- Исходные значения сохраняются с DPAPI до изменения. При отключении проверяется, что параметры ещё совпадают с применёнными. После аварийного выхода следующий запуск предлагает восстановление при том же условии. При отказе доступен локальный режим. Чтобы повторить запрос восстановления, откройте программу заново.
- Ядро привязывается к процессу приложения через Windows Job Object. Автозапуск с Windows отсутствует. **Туннель** отключён в этой версии.

Профили и запись восстановления хранятся в `%LOCALAPPDATA%\PomogatorVpn`, зашифрованные DPAPI текущего пользователя. Конфигурация передаётся ядру через stdin. Журнал и его TXT-экспорт содержат только итоги проверок и коды ошибок. Вывод ядра, адрес подписки и секреты в журнал не попадают.

## Диагностика

Приложение проверяет разрешение адреса сервера и TCP-доступ, запуск ядра, принадлежность локального порта процессу Xray и запрос HTTPS через локальный прокси. Для подтверждения прохождения трафика используется `https://www.gstatic.com/generate_204` с проверкой сертификата и ожидаемым HTTP 204. Проверка использует один исходящий VLESS без прямого маршрута. Она подтверждает прохождение запроса по указанному профилю, но не определяет страну или публичный IP выхода. Тайм-аут DNS на стороне VPN, фильтрация контрольного адреса и TLS-ошибка могут препятствовать проверке.

## Сборка и тесты

Из корня репозитория с .NET SDK 8 на Windows:

```powershell
dotnet run --project windows/vpn/tests/Tests.csproj -c Release
dotnet publish windows/vpn/app/PomogatorVpn.csproj -c Release -r win-x64 --self-contained true -o windows/vpn/dist
./windows/vpn/scripts/Get-Xray.ps1 -Destination windows/vpn/dist
```

Скрипт проверяет SHA‑256 архива Xray и добавляет бинарник и лицензию. Для интеграционных тестов задайте `POMOGATOR_TEST_XRAY` абсолютным путём к проверенному бинарнику. Тест запускает сервер и клиент VLESS на loopback и проверяет HTTPS через них с синтетическим профилем. Для теста реального WinINet используйте `POMOGATOR_TEST_WININET=1` только на изолированном Windows-раннере без действующего прокси.

На целевом Windows 10 отдельно проверьте открытие окна, подключение через реальный сервер, переключение системного прокси с сохранением PPPoE и ICS и восстановление после отключения. Для проверки локального режима можно указать HTTP-прокси в отдельном приложении без изменения настроек Windows.
