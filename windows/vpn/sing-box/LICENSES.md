# Лицензии экспериментальной сборки

`sing-box.exe` является отдельным процессом на базе sing-box v1.14.4, GPL-3.0-or-later. Он использует модифицированный sing-tun из закреплённого коммита и его лицензию из исходного дерева. Файлы лицензий ядра входят в комплект. Патчи ПОМОГАТОРА к этим двум проектам распространяются на условиях тех же лицензий. Сборка содержит Wintun. Условия распространения Wintun приведены в `WINTUN-LICENSE.txt`, а лицензии остальных библиотек находятся рядом с их исходным кодом.

Артефакт `Pomogator-sing-box-corresponding-source` в том же запуске GitHub Actions содержит соответствующий исходный код обоих модифицированных проектов, зависимости в каталоге `vendor`, патчи и команду сборки. Исходники и бинарный архив доступны в одном месте на одинаковых условиях. Из локально скачанного артефакта можно повторить сборку командой ниже из каталога `sing-box` с Go 1.25.5 и значениями `CGO_ENABLED=0`, `GOOS=windows`, `GOARCH=amd64`.

```powershell
go build -mod=vendor -trimpath -tags 'with_utls,with_gvisor' -ldflags '-s -w -checklinkname=0 -X github.com/sagernet/sing-box/constant.Version=1.14.4-pomogator' -o sing-box.exe ./cmd/sing-box
```

WPF запускает ядро как самостоятельный процесс и передаёт совместимую JSON-конфигурацию через стандартный ввод. Режимы прокси используют отдельный Xray и его лицензию MPL 2.0.
