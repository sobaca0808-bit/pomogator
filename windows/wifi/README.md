# ПОМОГАТОР Wi-Fi v0.1.1

Небольшая утилита Windows для раздачи активного подключения PPPoE через Hosted Network и общий доступ Windows (ICS). Требуются .NET Framework 4.8 и драйвер Wi-Fi с поддержкой Hosted Network. Python и установка утилиты не нужны.

## Запуск

1. Подключите Ralink по USB и подключите PPPoE в Windows. Проверьте, что на компьютере открывается сайт.
2. Запустите `PomogatorWifi.exe` из папки `release` и подтвердите запрос прав администратора Windows.
3. Введите имя сети и пароль. Имя допускает до 32 байт UTF-8, пароль — от 8 до 63 печатных символов ASCII.
4. Нажмите **Включить Wi-Fi**. Когда утилита покажет два подключения, убедитесь, что источником указан ваш PPPoE, а получателем — виртуальный адаптер Hosted Network. Подтвердите включение ICS. Windows также может показать собственный запрос.
5. На HONOR 600 Pro подключитесь к указанной сети и откройте сайт. Чтобы проверить именно раздачу Wi-Fi, можно временно выключить мобильные данные на телефоне.
6. Чтобы закончить, нажмите **Выключить Wi-Fi**. Если утилита включила ICS, она попросит подтвердить выключение. Проверьте, что компьютер по-прежнему в интернете.

Если проверка ICS не прошла или вы отклонили запрос, точка Wi-Fi может работать отдельно. Утилита не включает общий доступ без проверенной пары и подтверждения. Выключите точку и включите снова, чтобы повторить настройку ICS.

Индикатор **ICS настроен** означает, что Windows показала правильные роли у обоих подключений. Доступ телефона к интернету проверяется на самом телефоне.

## Диагностика

- **Hosted Network недоступна.** Проверьте подключение Ralink, службу «Автонастройка WLAN» (`services.msc`) и вывод `netsh wlan show drivers`. Если драйвер поддерживает Hosted Network, посмотрите её режим командой `netsh wlan show hostednetwork`. Если режим запрещён, включите его вручную только если это разрешено в вашей системе.
- **PPPoE не найдено.** Откройте `ncpa.cpl` и проверьте состояние «Высокоскоростного подключения». Утилита определяет PPPoE по типу и состоянию сетевого подключения. При нескольких активных PPPoE она останавливается до выбора пары.
- **ICS уже используется или произошла ошибка.** Откройте `ncpa.cpl`, затем свойства нужного подключения и вкладку «Доступ». Утилита не заменяет действующую настройку другой пары. Если Windows отклоняет изменение, проверьте состояние службы «Общий доступ к подключению к Интернету (ICS)».
- **Сбой или принудительное завершение.** Windows закрывает сеанс Hosted Network вместе с процессом. Настройки ICS могут сохраниться. В таком случае проверьте вкладку «Доступ» у PPPoE, прежде чем менять её вручную.

Журнал доступен по ссылке в окне и находится в `%LOCALAPPDATA%\PomogatorWifi\diagnostic.log`. Он содержит время, этапы, имена COM-операций, GUID выбранных подключений и коды HRESULT. При сбое ищите строку с `checks_failed` или `ics_setup_failed` в сеансе `version=0.1.1`. Имя Wi-Fi, пароль и учётные данные PPPoE в журнал не записываются. Windows использует введённый Wi-Fi-пароль только на один сеанс. Введённое имя точки сохраняется как параметр Hosted Network, существующий лимит клиентов сохраняется.

## Сборка и проверка

Из корня репозитория с установленным .NET SDK 8:

```powershell
dotnet build windows/wifi/PomogatorWifi.csproj -c Release
dotnet run --project windows/wifi/tests/PolicyTests.csproj -c Release
```

Результат сборки — `windows/wifi/bin/Release/net48/PomogatorWifi.exe`. Автоматические проверки покрывают объявления COM, обработку результата перечисления, диагностику HRESULT, выбор PPPoE, проверку пары, конфликт с существующим ICS, условия отката и ограничения полей. Проверку UAC, API Windows, появления виртуального адаптера, выдачи IP смартфону и доступа к интернету нужно выполнить на целевом ПК.
