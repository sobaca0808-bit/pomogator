# ПОМОГАТОР Wi-Fi Lite 0.1.0

Самостоятельный EXE для Windows 10 x64 с .NET Framework 4.8, который входит в Windows 10 22H2. Lite управляет одним сеансом Hosted Network через Windows WLAN API. Нужны драйвер с поддержкой Hosted Network и работающая служба «Автонастройка WLAN» (WlanSvc).

## Запуск и проверка

1. Штатно остановите прежнюю точку тем способом, которым она была запущена. Закройте прежний ПОМОГАТОР Wi-Fi. Он может удерживать точку через помощник после закрытия окна, поэтому сначала используйте его команду остановки. Подключите Ralink и обычное PPPoE.
2. Распакуйте архив Windows x64 и запустите `PomogatorWifiLite.exe`. Введите SSID и пароль WPA2 из 8–63 печатных символов ASCII. Нажмите **Запустить**. Lite ждёт подтверждения активной точки и виртуального адаптера от Windows. Для испытания удобно выбрать отдельное имя и заведомо известный пароль. Имя применяется в параметрах Hosted Network Windows. Пароль используется как вторичный ключ текущего сеанса и очищается из поля после успешного запуска.
3. На телефоне выберите новый SSID и введите пароль. Проверьте увеличение счётчика **Клиенты** и появление IPv4 в сведениях о подключении на телефоне. Ошибка по WLAN отображается с названием операции, кодом Win32 и причиной Hosted Network, если Windows её вернула. Отдельные отказы WPA2 Windows может оставить без уведомления. В таком случае пригодится точное сообщение телефона.
4. После подключения проверьте строку **ICS**. Lite читает роли и показывает найденные имена пары. При выключенном ICS откройте `ncpa.cpl`, свойства своего активного PPPoE, вкладку **Доступ**. Вручную разрешите общий доступ только указанному виртуальному адаптеру. Если Windows уже использует другую пару или не удалось надёжно определить адаптер, сначала разберитесь с текущими ролями. Иногда ICS показывает уже расшаренное PPPoE как общий WAN. Lite подтверждает тип PPPoE по GUID, если ранее в этом запуске видел тот же GUID как PPPoE.
5. Отключите мобильные данные на телефоне и откройте сайт. Повторите раздельно для двух других телефонов, затем подключите все три и проверьте счётчик и доступ каждого. Кнопка **Остановить** освобождает сеанс Lite. Закрытие окна тоже завершает сеанс. Настроенные вручную роли ICS относятся к Windows и сохраняются по её правилам.

Lite оставляет конфигурацию PPPoE, VPN, сетевых адаптеров, маршрутов, DNS и служб в исходном виде. Состояние ICS отражает роли Windows. Проверку интернет-доступа подтверждает подключённый телефон.

## Если Windows не запускает точку

`netsh wlan show drivers` показывает поддержку Hosted Network. `netsh wlan show hostednetwork` показывает состояние и число клиентов. Если Lite сообщает о выключенном радио или недоступной WlanSvc, проверьте эти параметры в Windows. Win32 31 с причиной WLAN 19 означает, что Windows или драйвер отклонили старт. Скопируйте код и название операции из окна. Причина отказа на физическом Ralink устанавливается по этому коду и результату испытания на том же ПК.

## Сборка и тесты

```powershell
dotnet run --project windows/wifi-lite/tests/PolicyTests.csproj -c Release
dotnet build windows/wifi-lite/PomogatorWifiLite.csproj -c Release
dotnet build windows/wifi-lite/tests/smoke/WifiLiteSmoke.csproj -c Release
& windows/wifi-lite/tests/smoke/bin/Release/net48/WifiLiteSmoke.exe
```

EXE находится в `windows/wifi-lite/bin/Release/net48`. CI проверяет модель запуска, остановки и трёх клиентов, WinForms и чтение Windows API. Физический Ralink, аутентификацию WPA2 и доступ по PPPoE с телефонов проверяйте на целевом Windows 10.
