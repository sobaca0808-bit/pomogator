# ПОМОГАТОР для Windows x64

Распакуйте ZIP и запустите `Pomogator.exe`. Органайзер откроется в браузере по адресу
`http://127.0.0.1:47821/`. Если вкладка не открылась, введите этот адрес вручную.
Чтобы остановить приложение, закройте окно запуска. Для работы интернет не нужен.

Карточки сохраняются в профиле браузера. При следующем запуске используйте тот же
профиль и адрес. Для переноса с GitHub Pages или с другого адреса экспортируйте JSON
из прежней версии и импортируйте его в тестовую сборку. Импорт заменяет данные
текущего адреса после подтверждения, поэтому сначала экспортируйте его базу, если
она уже заполнена. Не используйте приватное окно для постоянного хранения.

Ручная проверка. Откройте каждый из пяти разделов с экрана «Обзор». Создайте
«Платёж» в папке «Финансы», заполните поля и нажмите «Готово». Закройте вкладку и
окно запуска, снова откройте EXE и проверьте карточку в «Финансах».
