# ПОМОГАТОР v0.2

Персональный органайзер. Один раз настроил — всё под рукой.

## Запуск

Нужны Node.js 20.19+ из ветки 20 или Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Приложение хранит данные в IndexedDB текущего браузера, профиля и адреса. Для работы с существующей базой откройте новую версию на прежнем адресе с тем же протоколом и портом. Для переноса базы на другой адрес или в другой браузер используйте импорт и экспорт JSON.

## Возможности

- **Обзор.** Сегодняшние карточки, ближайшие дела, платежи, проекты, недавние карточки и избранные ссылки. Настройки видимости и порядка находятся в меню «Виджеты». Сочетание **Ctrl+K** или **⌘K** открывает глобальный поиск.
- **Разделы и папки.** Шесть стартовых разделов, собственные разделы, иконки, порядок и вложенные папки. Выбирайте папку в свойствах карточки для перемещения.
- **Карточки.** Семь шаблонов и 14 типов блоков. В карточках можно менять форму текста, упорядочивать блоки, связывать записи, добавлять чек-листы, таблицы и вложения.
- **Проекты и дела.** Подпроекты и подзадачи, статус, сроки, приоритеты, выполнение по чек-листу и последние 30 изменений. Суммы в карточке проекта можно использовать для записи бюджета.
- **Календарь.** Даты и напоминания из всех разделов. Повторы ежедневно, еженедельно или ежемесячно. Завершение карточки прекращает её будущие повторы. Уведомления доступны внутри приложения и, с разрешения браузера, при открытой странице.
- **Финансы.** Доходы, расходы, запланированные платежи, фильтр по дате, расходы по категориям и CSV. Укажите «Выполнено», чтобы включить операцию в баланс. Повторы отображаются в календаре и обзоре, проводить операции нужно вручную.
- **Документы и сервисы.** Просмотр обычного текста и изображений PNG, JPEG, WebP, GIF и AVIF, скачивание оригиналов, категории и теги. Ссылки принимаются с `http://` и `https://`.

## Сохранение и резервные копии

Карточка сохраняется после короткой паузы ввода. Дождитесь надписи «Сохранено в этом браузере» или нажмите «Готово». При ошибке содержимое остаётся в редакторе. После подтверждённого удаления карточки, папки или раздела доступна отмена последнего удаления до закрытия или обновления страницы. Удалённый блок можно вернуть в открытом редакторе.

База v0.1 читается на месте. Поля старой записи отображаются как блоки и сохраняются при редактировании. Резервные копии v0.1 поддерживаются. Экспорт v0.2 включает вложения, настройки, папки и карточки. Импорт проверяет структуру и содержимое вложений перед показом подтверждения. После подтверждения база заменяется одной транзакцией. Перед заменой сохраните текущую резервную копию. Размер хранилища зависит от браузера, удаление данных сайта очищает базу.

Плановые напоминания при закрытом приложении, полноценный WYSIWYG, автоматические финансовые проводки, отдельный учёт каждого повтора и просмотр PDF внутри приложения отложены. В репозитории есть манифест и иконка для PWA. Для офлайн-запуска без открытой или доступной страницы потребуется service worker.

## Тесты и сборка

```bash
npm test
npm run build -- --base=./
npx playwright install chromium
npm run test:e2e
npm run preview
```

Сборка создаётся в `dist/`. Готовую сборку нужно открыть через HTTP, например командой `python -m http.server 4173 --directory dist` и адресом `http://localhost:4173`. GitHub Actions проверяет Vitest и Playwright и прикрепляет архив со сборкой и снимками. Для собственного системного Chromium передайте его путь через переменную `POMOGATOR_CHROMIUM`.

В браузере тестируются вложенные папки, автосохранение со сменой страницы, поиск, удаление и отмена, импорт и экспорт с реальными байтами вложения, виджеты, календарь и мобильная компоновка. Скриншоты используют вымышленные данные, которые загружаются только в тестовом браузере.

## Тестовая версия для Windows и Android

Для Windows x64 скачайте `Pomogator-organizer-win-x64-test`, распакуйте ZIP и запустите
`Pomogator.exe`. Для Android скачайте `Pomogator-organizer-android-web-test` и разместите
содержимое ZIP на тестовом HTTPS-адресе. Откройте этот адрес в Chrome на телефоне.
Сборка для Android распространяется как адаптивное веб-приложение. Публикация
существующей версии на GitHub Pages от сборки тестовых ZIP не меняется.

В обоих вариантах используйте один и тот же адрес и профиль браузера при повторных запусках.
При смене адреса переносите карточки через резервную копию JSON.

## Постоянный тестовый стенд

Откройте [ПОМОГАТОР v0.2](https://sobaca0808-bit.github.io/pomogator/preview-v0.2/).
В Chrome на Android выберите в меню «Установить приложение» или «Добавить на главный
экран». При открытии заново или обновлении страницы приложение запрашивает свежую
страницу. Уже открытая вкладка продолжает работать с текущей сборкой до обновления,
поэтому можно сначала закончить редактирование. Для запуска нужна сеть.

Данные стенда хранятся в IndexedDB в профиле браузера под прежним именем
`pomogator-v02-pages`. Сборки используют постоянный адрес и сохраняют эту базу.
Для резервной копии используйте «Экспорт JSON».

Тесты исходной ветки `organizer-v0.2-fixes` запускаются при каждом push. После
их прохождения публикация на разрешённой ветке `organizer-v0.2-pages` берёт
проверенный коммит. Прогон со сборкой содержит ZIP Windows x64. Прогон Pages
содержит результат проверки доступности опубликованного коммита.

Формат сообщения о каждом обновлении:

- Версия программы и коммит.
- Выполненные изменения.
- Результаты проверок и ссылка на CI.
- Мобильный HTTPS-стенд.
- ZIP Windows x64.
- Рабочая ветка GitHub.
