# ПОМОГАТОР v0.1

Персональный органайзер. Один раз настроил — всё под рукой.

## Локальный запуск

Нужны Node.js 20.19+ из ветки 20 или Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Данные сохраняются в IndexedDB текущего браузера и адреса приложения.

## Проверка

```bash
npm test
npm run build
npm run preview
```

Тесты Vitest проверяют модель органайзера и транзакции через fake-indexeddb. Production-сборка создаётся в `dist/`. Preview использует отдельный адрес и отдельную локальную базу, если его порт отличается от порта сервера разработки.

Для проверки в браузере:

1. Откройте приложение и проверьте наличие шести стартовых разделов. Создайте раздел, выберите иконку, переименуйте и передвиньте через кнопки на карточке.
2. Создайте две вложенные папки. Добавьте запись с текстом, ссылкой, пунктом чек-листа, датой и суммой. Отметьте пункт и переместите запись, изменив поле «Расположение».
3. Найдите запись по слову из её текста с другим регистром. Обновите страницу и проверьте, что запись и разделы сохранились.
4. Экспортируйте JSON. Измените данные, импортируйте копию и проверьте отмену и подтверждение замены. Попробуйте импортировать повреждённый JSON.
5. Проверьте удаление раздела с содержимым. Повторите основные сценарии на узком экране.

## Хранение

Создание и редактирование записей фиксируются по кнопке «Сохранить». Смена порядка, отметки чек-листа и подтверждённое удаление сразу записываются в IndexedDB. Экспорт JSON включает всю базу и подходит для переноса между браузерами. Подтверждённый импорт полностью заменяет локальную базу. Очистка данных сайта в браузере удалит локальную копию.

В комплект входят веб-манифест и иконка для будущего PWA. Офлайн-запуск через service worker в версии 0.1 отсутствует.
